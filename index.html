01 About

I finish things, and I write down why they work.

I build games in Roblox Studio, tools in Python, and assets in Blender. What ties them together is the habit underneath: every project keeps a record of what I decided, what broke, and the rule I wrote so it wouldn't break the same way twice.

That habit produced two Roblox games taken from an empty baseplate to playable, a desktop app now in the hands of outside testers, and a Python toolchain that reads a live game API and generates search filters from it. The Blender work came out of a training log of 91 logged errors that ended in ten permanent modelling rules.

I'm studying geography on a geospatial track, heading toward GIS and Python for spatial data — QGIS, GeoPandas, remote sensing. The programming I already do is the programming that field runs on.
